# 真机验收清单

本清单尚未执行。建议至少在 Android 8、12、14、15 各一台设备或模拟器上做功能验收；声音、震动和省电场景必须在实际手机上检查。

| 场景 | 操作与预期 |
| --- | --- |
| 安装启动 | 正常安装、首次打开无崩溃；小屏和横屏可滚动，底部开始按钮可访问 |
| 预设 | 三个模式分别选择 100 / 120 / 170，手动改速后即时生效 |
| 调节边界 | 40 和 220 均可播放；输入无效值提示纠正；加减不会越界 |
| 点按测速 | 以 0.5 秒间隔点按得到约 120；停两秒后重新采样 |
| 声音 | 仅声音、仅震动、两者开启分别检查；调音量；系统媒体音量为 0 时不出声 |
| 震动 | 强弱调节有变化；无振动马达设备禁用震动并启用声音 |
| 关闭提示 | 关闭最后一种提示方式时拒绝，并保持开关状态一致 |
| 暂停继续 | 暂停后立即停止声震，时长不再增长；恢复后继续累计 |
| 结束 | 运行和暂停时均能结束，计时和节拍数清零，无剩余通知和声音 |
| 定时 | 10 分钟累计运行后停止；中途暂停不计时；较短新定时小于已运行时长时停止 |
| 生命周期 | 旋转屏幕、返回桌面、锁屏、重新打开，不能叠加多个节拍线程，状态保持一致 |
| 通知 | Android 13+ 分别允许和拒绝通知权限；允许时通知中的暂停/结束可用 |
| 锁屏 | 纯震动和声音模式各锁屏连续运行至少 10 分钟，观察实际节拍稳定性 |
| 音频中断 | 其他应用抢占音频焦点或拔下有线耳机时暂停；由用户再次开始 |
| 厂商省电 | 默认省电策略下锁屏检查，记录机型与任何中断现象 |
| 杀进程 | 系统终止后不自动重启播放；再次打开恢复设置但不恢复训练计数 |
| 资源释放 | 暂停、结束后通过 dumpsys 检查无 StepBeat 唤醒锁和震动占用 |

连接手机并开启 USB 调试后可安装：

```powershell
adb install -r .\dist\stepbeat-debug.apk
adb shell am start -n com.stepbeat.app/.MainActivity
adb logcat -s AndroidRuntime
```
